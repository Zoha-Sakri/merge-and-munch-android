# Android Project Context

`app/src/main/java/com/mergeandmunch/market` contains the Compose app. `GameViewModel` owns farm plots, board merges, orders, rewards, and shop state; `MainActivity` renders Farm, Market, and Shop routes.

Keep Android 10/API 29 as the minimum, use current installed SDKs, and keep the native experience aligned with the Web loop without copying protected game content.
