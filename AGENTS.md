# Android Agent Guide

This is the Kotlin/Jetpack Compose client for the original Merge & Munch farming-city game. The core loop is harvest crops, merge ingredients, serve orders, earn coins/stars, improve the town, and explore Ancient City tunnels.

Android 10/API 29 is the minimum (`minSdk`). Use the existing Compose structure and keep layouts usable on small screens. Do not copy Farm City branding, art, text, maps, characters, or exact progression.

Validate by opening the project in Android Studio and building/running on an Android 10+ emulator or device.
