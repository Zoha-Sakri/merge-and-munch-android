# Merge & Munch — Android

Native Android game using Kotlin and Jetpack Compose. The supported baseline is Android 10 (API 29); the project targets the current Android SDK configured in `app/build.gradle.kts`.

The client includes the original end-to-end loop: harvest farm plots, merge ingredients on the market board, serve customer orders for coins and stars, and buy farm decorations. Open this folder in Android Studio, let Gradle sync, and run `app` on an Android 10+ device or emulator.
